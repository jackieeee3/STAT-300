Question 1: Certain statistics courses include a midterm exam (out of 100) and a project (out of 30). Below, the least squares model was obtained using the data from 24 students in the class. \[\hat{Final} = 11.0 + 0.53Midterm + 1.20Project\]

(a). What would this tell you about a student who got a perfect score on the midterm and the project?

The student received a perfect score on the midterm and the project so the value for Midterm = 100 and the value for Project = 30. Plugging the values into the least squares model gives \[\hat{Final} = 11.0 + 0.53(100) + 1.20(30) = 11 + 53 + 36 = 100\] The expected score for the student’s final exam is 100.

(b). Leo got 87 on the midterm and 21 on the project, and 80 on the final exam. Calculate the residual and write a sentence explaining what this means in Leo’s case.

For Leo, \[\hat{Final} = 11.0 + 0.53(87) + 1.20(21) = 11.0 + 46.11 + 25.2 = 82.31\] But the observed value of the final exam for Leo is 80. Thus, \[Residual = Observed Value - Expected Value \Rightarrow Residual = 80 - 82.31 = -2.31\] The residual is negative, meaning Leo’s performance was worse than the model predicted.

(c). Does the fitted model above suggest that the project score has a stronger relationship with final exam score than the midterm score. Explain your answer.

Yes. The coefficient for the project equals 1.2 which is larger than the coefficient for the midterm which equals 0.53. A larger coefficient suggests that the variable has a stronger relationship with the final exam score.

(d). Interpret \(\hat{\beta_2}\) in the context of the problem.

\(\hat{\beta_2}\) is the expected increase in final exam score for a point increase in project score.

Question 2: State whether the statements below are true of false with an explanation

(a). For MLR, the \(Adj - R^2\) will always be smaller than \(R^2\) value. HINT: Two formulas can be written as below. \[R^2 = 1 - \frac{SSE}{SSTotal}\] \[Adj - R^2 = 1 - \frac{(n - 1)}{(n - k - 1)} \frac{SSE}{SSTotal}\]

True. When k = 0, \[Adj - R^2 = 1 - \frac{(n - 1)}{(n - 1)} \frac{SSE}{SSTotal} = 1 - \frac{SSE}{SSTotal} = R^2\] When k > 0, \[(n - 1) > (n - k - 1) \Rightarrow \frac{(n - 1)}{(n - k - 1)} > 1\] \[\Rightarrow \frac{(n - 1)}{(n - k - 1)} \frac{SSE}{SSTotal} > \frac{SSE}{SSTotal} \Rightarrow 1 - \frac{(n - 1)}{(n - k - 1)}\frac{SSE}{SSTotal} < 1 - \frac{SSE}{SSTotal}\] \[\Rightarrow Adj - R^2 < R^2\]

(b). If we fit a MLR model and then add a new predictor to the model, the \(Adj - R^2\) will always increase.

False. The adjusted R-squared can decrease if the new predictor does not improve the model. \(Adj - R^2\) penalizes for adding more variables into the model
